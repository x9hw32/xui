iOS26Anim 0.2.0

by Stealth2115

iOS 26-style app opening and closing animations for iPhone 8 on iOS 16. Upstream source by Stealth2115; rootless and rootful packages built by rajok. Revision rajok.2 fixes the iOS 16 spring settings class name and also applies response/damping through setters for cached presets. Original tuning is preserved. This is an approximation of iOS 26 animations, not its Metal rendering.

Upstream tuning: 1.50-second opening/closing duration, spring response 0.90, damping 0.60 and blur alpha 0.95. Version 0.2.0 adds Settings → iOS26Anim: enable/disable, separate open/close duration, spring response and damping, blur toggle and opacity, reset, and Apply and respring. Russian/English localization.
